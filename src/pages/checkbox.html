Checkbox

Checkboxes are used to toggle an option on or off.

Attributes

Name Description Default Reactive Required
radius Controls how rounded the corners are.
Allowed values: full | none		 - false false
size Controls the overall size of the element.
Allowed values: sm | md | lg		 md false false
config Additional attributes: id, name, value, class. - false false
checked false true false
indeterminate false true false
required false true false
disabled false true false

Default


<ui-checkbox></ui-checkbox>

Config

Each property in the JSON config must be enclosed in double quotes, both property names and their values, except for the boolean values true and false.

<ui-checkbox
  config='{
    "id":"unique-id",
    "class":"utility-class",
    "name":"product-id",
    "value":"on"
  }'>
</ui-checkbox>

Label

There are two ways to add a label to a component: either by wrapping the component inside a <label>, or by linking a separate <label> to the component using the for attribute with the component's id.

<label>
  Label <ui-checkbox></ui-checkbox>
</label>

<label for="input">Label</label>
<ui-checkbox config='{"id":"input"}'></ui-checkbox>
