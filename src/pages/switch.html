Switch

Switches provide a simple and user-friendly way to toggle between two states.

Attributes

Name Description Default Reactive Required
radius Controls how rounded the corners are.
Allowed values: full | none		 - false false
size Controls the overall size of the element.
Allowed values: sm | md | lg		 md false false
config Additional attributes: id, name, value, class. - false false
checked false true false
required false true false
disabled false true false

Default


<ui-switch></ui-switch>

Config

Each property in the JSON config must be enclosed in double quotes, both property names and their values, except for the boolean values true and false.

<ui-checkbox
  config='{
    "id":"unique-id",
    "class":"utility-class",
    "name":"product-id",
    "value":"on"
  }'>
</ui-checkbox>
