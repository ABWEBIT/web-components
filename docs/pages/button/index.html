Button

Buttons are used to perform actions or submit forms.

Attributes

Name Description Default Reactive
radius Controls how rounded the corners are.
Allowed values: full | none		 - false
size Controls the overall size of the element.
Allowed values: sm | md | lg		 md false
color Controls the color style of the element.
Allowed values: red | green | blue | yellow		 - false
disabled Disables the button. false true
busy Controls the button's loading state. false true

Config

Each property inside the config JSON string must be enclosed in double quotes. This applies both to the property names and their values.
Button 

<ui-button
  config='{
    "id":"unique-id",
    "class":"utility-class",
    "type":"submit"
  }'>
</ui-button>
